The sherpa-onnx Android library (`sherpa-onnx-<version>.aar`) is downloaded into this
folder automatically by the `downloadSherpaOnnxAar` Gradle task the first time you build.

If your build machine has no internet access, download the file manually from
https://github.com/k2-fsa/sherpa-onnx/releases (asset `sherpa-onnx-<version>.aar`, the
version is set in `app/build.gradle.kts`) and place it here.
